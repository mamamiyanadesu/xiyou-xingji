# 西游行记 · 读进山河

百度地图开发者大赛参赛作品。以《西游记》原著为线索，把三站试读、原文节选、古今地点对照和真实地图行程连成一条可以读、也可以走的西行之路。

## 已经能做什么

- 故事长卷：三个试读站（长安出发、西梁女国、小雷音寺），章节顺序示意，不冒充真实地理比例。
- 读原文：站内直接打开第 13、54、65 回全文，转录自维基文库，保留繁体字形并附来源链接。
- 古今对比：每站标注关联依据与出处，明确区分「历史关联」「文化比较」「暂无可靠对应」；没有可靠依据的地点不放坐标。
- 现实地图：接入百度地图 JSAPI 4.0，在地图中查看关联地点、确认候选目的地、计算附近距离。
- 行程规划：同一区域最多 5 站，步行或驾车，查询真实路线与时间，超出预算时可生成保留必去地点的精简建议。
- 通关文牒：标记已读、记录到访（手动或一次性定位辅助）、写心得，只保存在当前浏览器，可导出导入 JSON 备份。

## 技术

纯静态前端，无构建步骤：原生 ES Modules、CSS 自定义属性、百度地图 JSAPI 4.0。阅读与行程记录存在 `localStorage`，不上传任何服务器。

## 本地运行

```bash
node server.mjs
```

终端会打印本地预览地址。单元测试：

```bash
node --test tests/*.test.mjs
```

## 接入百度地图

网页使用的是浏览器端 JSAPI AK（不是 MCP 服务端密钥，也不是 SK）。两种接入方式：

1. 打开站内「配置地图服务」页，输入浏览器端 AK，仅保存在当前标签页会话，适合演示；
2. 正式部署时在百度地图控制台创建 JSAPI 浏览器 AK，并把部署域名加入 Referer 白名单。

详细步骤见 [DEPLOY.md](DEPLOY.md)。

## 内容边界

- 文学路线不等于真实路线，页面内持续标注。
- 现实地点只标注有出处支撑的关联，不把影视印象当作原著证据。
- 原文来自公共领域的维基文库转录，每条内容都附可核对来源，见 `dist/sources.html`。

## 目录

- `dist/`：可部署的完整站点
- `tests/`：状态与校验单元测试
- `fetch-chapters.py`：从维基文库抓取并校验回目转录（可离线重跑）
- `docs/`：验收截图等过程材料
